# Ba0 Ba0 — Project Experience Showcase

An interactive 13-slide presentation of Ba0 Ba0 Pte. Ltd. project work across aerospace, pharmaceuticals, social services, semiconductor manufacturing, agriculture, logistics and mining.

- **Deck:** `Ba0Ba0_Project_Showcase.html`. It is a single self-contained file, with fonts, images and screenshots embedded, and it opens directly in a browser.
- **Hosting:** Vercel static site. `vercel.json` serves the deck at `/`.
- **Source:** `deck_src/`. Edit the text in `deck_src/assemble.py`, then run `python -I deck_src/assemble.py` to rebuild the deck. See `deck_src/README.md` for details.

## Presenter keys

- → ← Space: next and previous slide
- 1–4: jump to a chapter
- O: all slides
- F or F5: full screen
- L: laser pointer
- T: light or dark theme
- M: sound on or off
- Esc: close
